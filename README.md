# Cloud v3 — семестр.

Отдельный демонстрационный интерфейс учебного кабинета: Cloud, светлая и тёмная темы, регистрация с демонстрационным кодом, расписание и учебные разделы.

Только вымышленные данные. Настоящие SMS, авторизация, платежи, вызовы AI и подключение к БРСО отсутствуют. Не вводите реальные персональные данные.

В этот репозиторий публикуется только статический прототип. Репозиторий рабочего бота и production-сервисы не затрагиваются.
